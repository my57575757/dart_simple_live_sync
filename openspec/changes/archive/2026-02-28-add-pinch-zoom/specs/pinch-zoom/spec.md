## 新增需求

### 需求：双指捏合缩放
系统必须支持用户通过双指捏合手势缩放直播画面，缩放范围必须限制在 1.0x 至 4.0x 之间。

#### 场景：双指捏合放大
- **当** 用户在视频画面上执行双指张开手势
- **那么** 画面必须以手势中心点为锚点进行放大
- **并且** 缩放倍数不得超过 4.0x

#### 场景：双指捏合缩小
- **当** 用户在视频画面上执行双指捏合手势
- **那么** 画面必须以手势中心点为锚点进行缩小
- **并且** 缩放倍数不得小于 1.0x

#### 场景：缩放边界限制
- **当** 用户尝试缩放超过 4.0x 或低于 1.0x
- **那么** 系统必须将缩放倍数限制在有效范围内
- **并且** 画面不能超出视频边界

### 需求：双击重置缩放
系统必须支持用户在放大状态下双击画面重置缩放到 1.0x。

#### 场景：放大时双击重置
- **当** 当前缩放倍数大于 1.0x
- **并且** 用户双击视频画面
- **那么** 系统必须将缩放倍数重置为 1.0x
- **并且** 平移偏移量重置为零

#### 场景：未放大时双击全屏
- **当** 当前缩放倍数等于 1.0x
- **并且** 用户双击视频画面
- **那么** 系统必须执行全屏/退出全屏操作（保持现有行为）

### 需求：锁定状态禁用缩放
系统必须在锁定控制器状态下禁用所有缩放和平移操作。

#### 场景：锁定时禁用缩放
- **当** 控制器处于锁定状态（`lockControlsState = true`）
- **当** 用户尝试双指缩放或拖拽
- **那么** 系统必须忽略所有缩放和平移输入

### 需求：小窗模式禁用缩放
系统必须在桌面端小窗模式下禁用缩放功能。

#### 场景：小窗模式禁用缩放
- **当** 应用处于桌面端小窗模式（`smallWindowState = true`）
- **当** 用户尝试双指缩放
- **那么** 系统必须忽略缩放输入
- **并且** 保持 1.0x 缩放倍数

### 需求：切换直播间重置缩放
系统必须在用户切换直播间时重置缩放状态。

#### 场景：切换直播间重置
- **当** 用户切换到不同的直播间（调用 `resetRoom()`）
- **那么** 系统必须将缩放倍数重置为 1.0x
- **并且** 平移偏移量重置为零
