## 新增需求

### 需求：双指拖拽平移
系统必须支持用户通过双指拖拽手势平移已放大的画面。

#### 场景：双指拖拽平移
- **当** 画面缩放倍数大于 1.0x
- **当** 用户在视频画面上执行双指拖拽手势
- **那么** 画面必须跟随手指移动方向平移

#### 场景：平移边界限制
- **当** 用户拖拽画面至边缘
- **那么** 画面不能移出视频边界超过画面尺寸的 50%
- **并且** 松手后画面必须弹性回弹到有效范围内

### 需求：鼠标拖拽平移（桌面端）
系统必须支持桌面端用户通过鼠标拖拽平移已放大的画面。

#### 场景：鼠标左键拖拽平移
- **当** 应用运行在桌面平台（Windows/macOS/Linux）
- **当** 画面缩放倍数大于 1.0x
- **当** 用户按下鼠标左键并移动
- **那么** 画面必须跟随鼠标移动方向平移

#### 场景：鼠标右键拖拽平移
- **当** 应用运行在桌面平台（Windows/macOS/Linux）
- **当** 画面缩放倍数大于 1.0x
- **当** 用户按下鼠标右键并移动
- **那么** 画面必须跟随鼠标移动方向平移

### 需求：未放大时禁用平移
系统必须在画面缩放倍数为 1.0x 时禁用平移功能。

#### 场景：1.0x 缩放时禁用平移
- **当** 画面缩放倍数等于 1.0x
- **当** 用户尝试拖拽或鼠标平移
- **那么** 系统必须忽略平移输入
- **并且** 画面位置保持不变
