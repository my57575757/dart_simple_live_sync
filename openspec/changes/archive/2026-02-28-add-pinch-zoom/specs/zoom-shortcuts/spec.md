## 新增需求

### 需求：键盘缩放快捷键
系统必须支持桌面端用户通过键盘快捷键控制画面缩放。

#### 场景：加号键放大
- **当** 应用运行在桌面平台
- **当** 播放器区域获得焦点
- **当** 用户按下 `+` 键或 `=` 键
- **那么** 系统必须将缩放倍数增加 0.5x
- **并且** 缩放倍数不得超过 4.0x

#### 场景：减号键缩小
- **当** 应用运行在桌面平台
- **当** 播放器区域获得焦点
- **当** 用户按下 `-` 键
- **那么** 系统必须将缩放倍数减少 0.5x
- **并且** 缩放倍数不得小于 1.0x

#### 场景：Home 键重置
- **当** 应用运行在桌面平台
- **当** 播放器区域获得焦点
- **当** 用户按下 `Home` 键
- **那么** 系统必须将缩放倍数重置为 1.0x
- **并且** 平移偏移量重置为零

### 需求：键盘平移快捷键
系统必须支持桌面端用户通过方向键平移画面。

#### 场景：方向键上移
- **当** 应用运行在桌面平台
- **当** 画面缩放倍数大于 1.0x
- **当** 播放器区域获得焦点
- **当** 用户按下 `↑` 方向键
- **那么** 画面必须向上平移 50px

#### 场景：方向键下移
- **当** 应用运行在桌面平台
- **当** 画面缩放倍数大于 1.0x
- **当** 播放器区域获得焦点
- **当** 用户按下 `↓` 方向键
- **那么** 画面必须向下平移 50px

#### 场景：方向键左移
- **当** 应用运行在桌面平台
- **当** 画面缩放倍数大于 1.0x
- **当** 播放器区域获得焦点
- **当** 用户按下 `←` 方向键
- **那么** 画面必须向左平移 50px

#### 场景：方向键右移
- **当** 应用运行在桌面平台
- **当** 画面缩放倍数大于 1.0x
- **当** 播放器区域获得焦点
- **当** 用户按下 `→` 方向键
- **那么** 画面必须向右平移 50px

### 需求：快捷键焦点管理
系统必须确保键盘快捷键仅在播放器获得焦点时响应。

#### 场景：焦点获得
- **当** 用户点击视频画面区域
- **那么** 播放器必须获得键盘焦点
- **并且** 键盘快捷键开始响应

#### 场景：焦点失去
- **当** 用户点击播放器外部区域
- **当** 用户切换到其他应用
- **那么** 播放器必须失去键盘焦点
- **并且** 键盘快捷键停止响应
