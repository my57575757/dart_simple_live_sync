## 新增需求

### 需求：缩放倍数提示显示
系统必须在用户缩放画面时显示当前缩放倍数提示。

#### 场景：开始缩放时显示
- **当** 用户开始双指缩放或键盘缩放操作
- **那么** 系统必须在画面中央显示缩放倍数提示
- **并且** 提示格式为 "缩放 XX%"（例如 "缩放 200%"）

#### 场景：缩放过程中更新
- **当** 用户持续缩放操作
- **那么** 提示文本必须实时更新显示当前倍数
- **并且** 提示位置保持在画面中央

#### 场景：缩放结束后隐藏
- **当** 用户结束缩放操作（手指离开屏幕或松开键盘）
- **那么** 提示必须继续显示 2 秒
- **并且** 2 秒后提示自动淡出消失

### 需求：提示 UI 样式
系统必须确保缩放倍数提示的视觉风格与应用现有手势提示保持一致。

#### 场景：提示样式
- **当** 显示缩放倍数提示时
- **那么** 提示必须使用深灰色半透明背景（`Colors.grey.shade900`）
- **并且** 文字颜色必须为白色
- **并且** 文字大小必须为 18sp
- **并且** 圆角边框（`BorderRadius.circular(12)`）
- **并且** 内边距为 12px

#### 场景：与其他提示互斥
- **当** 正在显示亮度/音量提示时
- **当** 用户执行缩放操作
- **那么** 系统必须隐藏之前的提示
- **并且** 显示新的缩放倍数提示

### 需求：禁用状态下不显示提示
系统必须在特定状态下不显示缩放倍数提示。

#### 场景：锁定时不显示
- **当** 控制器处于锁定状态
- **当** 用户尝试缩放操作
- **那么** 系统必须忽略缩放输入
- **并且** 不显示缩放倍数提示

#### 场景：小窗模式不显示
- **当** 应用处于桌面端小窗模式
- **当** 用户尝试缩放操作
- **那么** 系统必须忽略缩放输入
- **并且** 不显示缩放倍数提示
