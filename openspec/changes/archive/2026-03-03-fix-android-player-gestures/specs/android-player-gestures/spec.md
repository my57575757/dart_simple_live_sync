## 新增需求

### 需求：双击全屏切换
系统必须支持在安卓端通过双击播放器画面来切换全屏模式。

#### 场景：双击触发全屏
- **当** 用户在非全屏模式下双击播放器画面
- **那么** 系统必须切换到全屏模式

#### 场景：双击退出全屏
- **当** 用户在全屏模式下双击播放器画面
- **那么** 系统必须退出全屏模式

### 需求：非全屏放大后手势识别区域
系统在非全屏放大模式下必须基于窗口左右侧识别音量/亮度滑动手势，而非基于放大后画面的左右侧。

#### 场景：非全屏放大后左侧滑动手势
- **当** 用户在非全屏放大模式下于窗口左侧区域垂直滑动
- **那么** 系统必须识别为亮度调节手势

#### 场景：非全屏放大后右侧滑动手势
- **当** 用户在非全屏放大模式下于窗口右侧区域垂直滑动
- **那么** 系统必须识别为音量调节手势

### 需求：非全屏放大后提示条位置
系统在非全屏放大模式下必须将音量/亮度提示条固定在窗口边缘，提示条不得随画面放大而移动或缩放。

#### 场景：非全屏放大后提示条显示
- **当** 用户调节音量或亮度时
- **那么** 系统必须在窗口边缘显示提示条，位置不受画面放大影响

### 需求：全屏放大功能
系统必须支持在全屏模式下进行画面放大操作。

#### 场景：全屏模式下放大
- **当** 用户在全屏模式下执行放大手势
- **那么** 系统必须正确放大画面
